# Aussie School Quiz

A free offline quiz game for Australian school students, Years 1–12, built for Android TV / Google TV.

![School Quiz](https://img.shields.io/badge/platform-Android%20TV%20%7C%20Google%20TV-green)
![Questions](https://img.shields.io/badge/questions-10%2C000-blue)
![License](https://img.shields.io/badge/license-MIT-lightgrey)

## What is it?

Pick your year level, pick a subject, and play a round of quiz questions. Every question comes with an explanation, so the game doubles as revision. No account, no internet needed — everything runs offline on the TV.

## Features

- **Years 1–12** in 5 bands: Years 1–2, 3–4, 5–6, 7–9, 10–12
- **10 subjects, 1,000 questions each (10,000 total)**, each with an explanation
  - Years 1–9: Mathematics, Science, English, HASS, Technology
  - Years 10–12: English, Mathematical Methods, Specialist Mathematics, Physics, Chemistry, Biology (SACE Stage 2 topics)
- **Choose your round size:** 10, 20, 30, 50 questions, or All
- **Review answers:** after each round, see every question marked ✓ / ✗, open any question to see your answer, the correct answer and why
- **Randomised every round:** question order and answer order are shuffled, so the correct answer never sits in a fixed spot
- **20 seconds per question**, +10 points per correct answer, best score saved per subject and round size
- **Music** with an on-screen Music On/Off button (or the MUTE key on the remote)

## Install on your TV

The app is a standard Android TV APK. Pick the easiest method:

### Option A — Downloader (AFTVnews)
1. Install **Downloader** from the Play Store (Android TV / Google TV) or Amazon Appstore (Fire TV).
2. Open Downloader and enter the APK link from the latest release below.
3. Tap **Go** to download, then **Install** (allow "Install unknown apps" for Downloader if asked).

### Option B — Send Files to TV
1. Install **Send Files to TV** on your TV and on your phone.
2. Send the APK file from your phone to the TV, then open it with a file manager and tap **Install**.

### Option C — USB
1. Copy the APK onto a USB drive (FAT32).
2. Plug it into the TV, open a file manager, tap the APK and install.

Requires Android 5.0+ (Android TV / Google TV). The app appears as **School Quiz** in your apps.
